This report documents the Phase 3.1 robustness experiment.

2. **Semantic Class Sensitivity:** Stability ranges from FACTUAL (CV=54%) to CODE (CV=99%).

## 2. The Lazare Protocol
Exogenous injection is **prophylactic, not therapeutic**. It prevents collapse if applied early but cannot reverse it past $t^* \approx 3-4$.
